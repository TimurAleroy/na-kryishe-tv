# На Крыше — экран для ТВ (прототип)

Одна страница на весь экран: заставка с логотипом, встреча по имени, поздравление, афиша, сезонные эффекты.

Открыть: https://timuraleroy.github.io/na-kryishe-tv/

Параметры адреса:
- `?name=Мария` имя гостя
- `?scene=idle|welcome|bday|event` показать одну сцену
- `?season=newyear|valentine|march8` включить сезон
- `?blur=18&bright=0.55&veil=0.38` размытие, яркость и затемнение фонового видео
- `?bg=0` без видео, `?demo` без запроса афиши с сервера

Клавиши: 1–4 сцены, S сезон, пробел пауза, F полный экран, H подсказка.

Фоновое видео: `bg.mp4` (H.264) и `bg.webm` лежат рядом с index.html. Сейчас это временный клип для примера (с Pinterest, правообладатель неизвестен). Для постоянной работы заменить на свой ролик: те же имена файлов, 15–20 секунд, без звука, лучше 1920×1080. Без файлов фон остаётся однотонным.
